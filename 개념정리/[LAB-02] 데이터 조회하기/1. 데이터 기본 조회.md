# 데이터 기본 조회

## SELECT 기본 구조

`SELECT`는 테이블에서 원하는 데이터를 조회할 때 사용한다.

```sql
SELECT 컬럼명
FROM 테이블명;
```

- `SELECT` : 조회할 컬럼을 지정
- `FROM` : 데이터를 조회할 테이블을 지정

### 전체 컬럼 조회

`*`를 사용하면 모든 컬럼을 조회할 수 있다.

```sql
SELECT *
FROM departments;
```

### 특정 컬럼 조회

조회하려는 컬럼명을 직접 지정할 수 있다.

```sql
SELECT dname, email, phone, loc
FROM departments;
```

필요한 컬럼만 명시해서 조회하는 것이 좋다.

---

## 컬럼에 별칭 적용하기

`AS`를 사용하여 조회 결과의 컬럼 이름에 별칭을 지정할 수 있다.

```sql
SELECT name AS 이름,
       position AS 직급,
       status AS '재직 상태'
FROM professors;
```

- `AS`는 생략 가능
- 별칭에 공백이 있으면 따옴표로 묶는다.

---

## 컬럼에 사칙연산 적용하기

컬럼에 사칙연산을 적용하여 조회할 수 있다.

```sql
SELECT name,
       position,
       sal * 12 + 100
FROM professors;
```

연산은 조회 결과에만 적용되며 원본 데이터는 변경되지 않는다.

연산 결과에 별칭을 지정할 수도 있다.

```sql
SELECT name,
       position,
       sal * 12 + 100 AS salary
FROM professors;
```

---

## 데이터 정렬하기

`ORDER BY`를 사용하여 조회 결과를 정렬한다.

```sql
SELECT 컬럼명
FROM 테이블명
ORDER BY 정렬기준;
```

- `ASC` : 오름차순
- `DESC` : 내림차순
- 정렬 방식을 생략하면 기본값은 `ASC`

### 오름차순

```sql
SELECT name, position, sal
FROM professors
ORDER BY sal ASC;
```

### 내림차순

```sql
SELECT name, position, sal
FROM professors
ORDER BY sal DESC;
```

### 여러 기준으로 정렬

정렬 기준을 쉼표(`,`)로 구분하여 여러 개 지정할 수 있다.

```sql
SELECT grade, name, gender
FROM students
ORDER BY grade ASC, name ASC;
```

먼저 `grade`를 기준으로 정렬하고, 같은 학년에서는 `name`을 기준으로 다시 정렬한다.

### 별칭을 이용한 정렬

연산 결과에 별칭을 지정했다면 `ORDER BY`에서 별칭을 사용할 수 있다.

```sql
SELECT name,
       position,
       sal * 12 + 100 AS salary
FROM professors
ORDER BY salary DESC;
```

연산식을 다시 작성하지 않아도 되므로 가독성이 좋고 중복 계산을 줄일 수 있다.

---

## LIMIT

`LIMIT`은 조회 결과의 범위를 제한할 때 사용한다.

### 상위 N개 조회

```sql
SELECT name, position, user_id, sal
FROM professors
ORDER BY sal DESC
LIMIT 5;
```

급여를 내림차순으로 정렬한 뒤 상위 5개의 데이터만 조회한다.

### 특정 위치부터 조회

```sql
SELECT id, dname, loc
FROM departments
LIMIT 3, 3;
```

기본 구조:

```sql
LIMIT 시작위치, 개수;
```

시작 위치는 `0`부터 계산한다.

- `LIMIT 0, 3` → 1번째부터 3개
- `LIMIT 3, 3` → 4번째부터 3개
- `LIMIT 6, 3` → 7번째부터 3개
- `LIMIT 9, 3` → 10번째부터 3개

---

## 핵심 정리

### SELECT 기본 순서

```sql
SELECT 컬럼명
FROM 테이블명
ORDER BY 정렬기준
LIMIT 개수;
```

### 주요 문법

| 문법 | 기능 |
|---|---|
| `SELECT` | 조회할 컬럼 지정 |
| `FROM` | 조회할 테이블 지정 |
| `AS` | 컬럼에 별칭 지정 |
| `ORDER BY` | 조회 결과 정렬 |
| `ASC` | 오름차순 |
| `DESC` | 내림차순 |
| `LIMIT` | 조회 결과의 범위 제한 |

**기억하기**

- `ORDER BY`의 기본 정렬 방식은 `ASC`
- 여러 정렬 기준은 쉼표(`,`)로 구분
- `LIMIT`의 시작 위치는 `0`부터 계산

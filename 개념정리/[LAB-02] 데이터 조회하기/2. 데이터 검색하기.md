# 데이터 검색하기

## WHERE 절

`WHERE`는 특정 조건을 만족하는 행(Row)만 조회할 때 사용한다.

```sql
SELECT 컬럼명
FROM 테이블명
WHERE 검색조건
ORDER BY 정렬기준
LIMIT 시작위치, 개수;
```

`WHERE`에서는 비교 연산자와 논리 연산자를 사용하여 검색 조건을 지정할 수 있다.

---

## 비교 연산자

값을 서로 비교하여 조건을 지정할 때 사용한다.

| 연산자 | 의미 |
|---|---|
| `=` | 같다 |
| `!=` | 다르다 |
| `<>` | 다르다 |
| `<` | 작다, 미만 |
| `<=` | 작거나 같다, 이하 |
| `>` | 크다, 초과 |
| `>=` | 크거나 같다, 이상 |

### 같은 값 조회

1학년 학생의 학번, 이름, 학년을 조회한다.

```sql
SELECT id, name, grade
FROM students
WHERE grade = 1;
```

### 같지 않은 값 조회

4학년이 아닌 학생의 학번, 학년, 이름, 키를 조회한다.

```sql
SELECT id, grade, name, height
FROM students
WHERE grade != 4;
```

`!=` 대신 `<>`를 사용할 수도 있다.

```sql
WHERE grade <> 4;
```

### 초과 조건 조회

키가 180cm를 초과하는 학생을 조회한다.

```sql
SELECT id, name, height, weight
FROM students
WHERE height > 180;
```

### 이상 조건 조회

급여가 300만원 이상인 교수를 급여가 높은 순으로 조회한다.

```sql
SELECT id, name, position, sal
FROM professors
WHERE sal >= 300
ORDER BY sal DESC;
```

---

## 논리 연산자

여러 개의 검색 조건을 함께 사용할 때 논리 연산자를 사용한다.

| 연산자 | 의미 |
|---|---|
| `AND` | 여러 조건을 모두 만족 |
| `OR` | 하나 이상의 조건을 만족 |
| `NOT` | 조건을 부정 |

---

## AND

여러 조건을 **모두 만족하는 데이터**를 조회한다.

예를 들어 1학년이면서 여학생인 학생을 조회한다.

```sql
SELECT id, name, grade, gender
FROM students
WHERE grade = 1 AND gender = '여';
```

문자열 형태의 값은 따옴표로 묶어서 사용한다.

---

## OR

여러 조건 중 **하나 이상을 만족하는 데이터**를 조회한다.

졸업했거나 휴학 중인 학생을 조회한다.

```sql
SELECT name, grade, gender, phone
FROM students
WHERE status = '졸업' OR status = '휴학'
ORDER BY grade ASC;
```

---

## 괄호를 사용한 복합 조건

`AND`와 `OR`를 함께 사용하는 경우 괄호를 사용하여 조건을 묶을 수 있다.

예를 들어 1학년 또는 2학년이면서 재학 중인 학생을 조회한다.

```sql
SELECT id, name, grade, gender, status
FROM students
WHERE (grade = 1 OR grade = 2)
  AND status = '재학'
ORDER BY grade ASC;
```

괄호를 사용하면 어떤 조건을 먼저 처리할지 명확하게 지정할 수 있다.

---

## AND와 OR의 우선순위

`AND`와 `OR`를 함께 사용할 때는 **AND가 OR보다 먼저 처리**된다.

다음과 같이 괄호 없이 작성하면

```sql
SELECT id, name, grade, gender, status
FROM students
WHERE grade = 1
   OR grade = 2 AND status = '재학'
ORDER BY grade ASC;
```

실제로는 다음과 같이 처리된다.

```sql
WHERE grade = 1
   OR (grade = 2 AND status = '재학')
```

따라서 1학년은 학적 상태와 관계없이 조회되고,  
2학년은 `재학` 상태인 학생만 조회된다.

원하는 조건을 정확하게 표현하기 위해서는 괄호를 사용하는 것이 좋다.

```sql
WHERE (grade = 1 OR grade = 2)
  AND status = '재학'
```

## 핵심 정리

### WHERE 기본 위치

```sql
SELECT 컬럼명
FROM 테이블명
WHERE 검색조건
ORDER BY 정렬기준
LIMIT 개수;
```

### 주요 연산자

| 구분 | 연산자 |
|---|---|
| 같음 | `=` |
| 다름 | `!=`, `<>` |
| 크기 비교 | `<`, `<=`, `>`, `>=` |
| 모든 조건 만족 | `AND` |
| 하나 이상 만족 | `OR` |
| 조건 부정 | `NOT` |

### 기억할 것

- `WHERE`는 조건을 만족하는 행만 조회한다.
- `>=`는 기준값을 포함하는 **이상**이다.
- `>`는 기준값을 포함하지 않는 **초과**이다.
- 문자열은 `'여'`, `'재학'`처럼 따옴표로 묶는다.
- 여러 조건을 모두 만족해야 하면 `AND`를 사용한다.
- 여러 조건 중 하나만 만족해도 되면 `OR`를 사용한다.
- `AND`는 `OR`보다 우선순위가 높다.
- 복합 조건은 괄호를 사용하면 조건을 명확하게 표현할 수 있다.

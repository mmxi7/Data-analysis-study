# SQL 검색 연산자

## BETWEEN

`BETWEEN A AND B`는 특정 범위에 포함되는 데이터를 조회할 때 사용한다.

```sql
SELECT 컬럼명
FROM 테이블명
WHERE 컬럼명 BETWEEN 값1 AND 값2;
```

`BETWEEN`은 시작값과 종료값을 **모두 포함**한다.

즉,

```sql
WHERE sal BETWEEN 400 AND 500;
```

은 다음 조건과 같다.

```sql
WHERE sal >= 400 AND sal <= 500;
```

### 사용 예시

급여가 400만원 이상 500만원 이하인 교수를 급여가 높은 순으로 조회한다.

```sql
SELECT id, name, sal
FROM professors
WHERE sal BETWEEN 400 AND 500
ORDER BY sal DESC;
```

### NOT BETWEEN

`NOT BETWEEN`은 지정한 범위에 포함되지 않는 데이터를 조회한다.

```sql
SELECT id, dname, established
FROM departments
WHERE established NOT BETWEEN 1985 AND 1995
ORDER BY dname ASC;
```

위 조건은 다음과 같다.

```sql
WHERE established < 1985 OR established > 1995;
```

## IN

`IN`은 여러 값 중 **하나와 일치하는 데이터**를 조회할 때 사용한다.

```sql
SELECT 컬럼명
FROM 테이블명
WHERE 컬럼명 IN (값1, 값2, ...);
```

여러 개의 `OR` 조건을 사용하는 것보다 간결하게 작성할 수 있다.

### 사용 예시

직급이 교수 또는 부교수인 교수를 조회한다.

```sql
SELECT id, name, position
FROM professors
WHERE position IN ('교수', '부교수')
ORDER BY name ASC;
```

위 조건은 다음과 같다.

```sql
WHERE position = '교수' OR position = '부교수';
```

### NOT IN

`NOT IN`은 목록에 포함되지 않은 데이터를 조회한다.

```sql
SELECT id, dname, loc
FROM departments
WHERE loc NOT IN ('공학관', '인문사회관')
ORDER BY dname ASC;
```

위 조건은 다음과 같다.

```sql
WHERE loc != '공학관' AND loc != '인문사회관';
```

## LIKE

`LIKE`는 문자열 데이터에서 특정 패턴과 일치하는 값을 조회할 때 사용한다.

```sql
SELECT 컬럼명
FROM 테이블명
WHERE 컬럼명 LIKE '패턴';
```

`LIKE`에서는 와일드카드(Wildcard) `%`를 사용하여 문자열의 패턴을 지정할 수 있다.

### % 와일드카드

`%`는 **0개 이상의 문자**를 의미한다.

| 패턴 | 의미 |
|---|---|
| `'김%'` | `김`으로 시작하는 문자열 |
| `'%김'` | `김`으로 끝나는 문자열 |
| `'%김%'` | `김`을 포함하는 문자열 |

### 사용 예시

학과 이름에 `공학`이라는 단어가 포함된 학과를 조회한다.

```sql
SELECT id, dname, established
FROM departments
WHERE dname LIKE '%공학%'
ORDER BY established DESC;
```

`%공학%`에서 앞뒤에 `%`가 있으므로 문자열의 위치와 관계없이 `공학`이 포함되어 있으면 조회된다.

### NOT LIKE

`NOT LIKE`는 특정 패턴과 일치하지 않는 데이터를 조회한다.

```sql
SELECT id, dname, established
FROM departments
WHERE dname NOT LIKE '%공학%'
ORDER BY established DESC;
```

위 쿼리는 학과 이름에 `공학`이라는 단어가 포함되지 않은 학과를 조회한다.

## IS NULL

`NULL`은 값이 없거나 결정되지 않은 상태를 의미한다.

특정 컬럼의 값이 `NULL`인 데이터를 조회할 때는 `IS NULL`을 사용한다.

```sql
SELECT 컬럼명
FROM 테이블명
WHERE 컬럼명 IS NULL;
```

### 사용 예시

홈페이지 주소가 없는 학과를 조회한다.

```sql
SELECT id, dname, homepage
FROM departments
WHERE homepage IS NULL;
```

### NULL 비교 시 주의사항

`NULL`은 일반적인 값이 아니기 때문에 `=` 연산자를 사용하지 않는다.

```sql
-- 잘못된 방법
WHERE homepage = NULL;
```

다음과 같이 작성해야 한다.

```sql
WHERE homepage IS NULL;
```

## IS NOT NULL

`IS NOT NULL`은 해당 컬럼에 `NULL`이 아닌 값이 저장되어 있는 데이터를 조회한다.

```sql
SELECT 컬럼명
FROM 테이블명
WHERE 컬럼명 IS NOT NULL;
```

### 사용 예시

졸업일이 입력되어 있는 학생을 조회한다.

```sql
SELECT id, name, status, graduation_date
FROM students
WHERE graduation_date IS NOT NULL;
```

## 핵심 정리

| 연산자 | 의미 |
|---|---|
| `BETWEEN A AND B` | A 이상 B 이하 |
| `NOT BETWEEN A AND B` | A 이상 B 이하의 범위가 아닌 값 |
| `IN (값1, 값2, ...)` | 목록 중 하나와 일치 |
| `NOT IN (값1, 값2, ...)` | 목록에 포함되지 않음 |
| `LIKE` | 특정 문자열 패턴과 일치 |
| `NOT LIKE` | 특정 문자열 패턴과 일치하지 않음 |
| `IS NULL` | NULL인 데이터 |
| `IS NOT NULL` | NULL이 아닌 데이터 |

### 기억할 것

- `BETWEEN A AND B`는 **A와 B를 모두 포함**한다.
- `IN`은 여러 개의 `OR` 조건을 간결하게 표현할 수 있다.
- `NOT IN`은 여러 개의 제외 조건을 표현할 수 있다.
- `LIKE`는 문자열의 특정 패턴을 검색할 때 사용한다.
- `%`는 0개 이상의 문자를 의미한다.
- `NULL`은 값이 없거나 결정되지 않은 상태이다.
- `NULL`을 찾을 때는 `= NULL`이 아니라 `IS NULL`을 사용한다.
- `NULL`이 아닌 데이터를 찾을 때는 `IS NOT NULL`을 사용한다.

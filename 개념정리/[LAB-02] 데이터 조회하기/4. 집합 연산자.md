# 집합 연산자

집합 연산자는 **두 개 이상의 SELECT문의 조회 결과를 하나의 결과로 결합하거나 비교**할 때 사용한다.

집합 연산자를 사용하려면 두 SELECT문의 조회 결과가 다음 조건을 만족해야 한다.

- 조회하는 **컬럼의 개수가 같아야 한다.**
- 서로 대응되는 컬럼의 **데이터 타입이 호환되어야 한다.**

---

## 1. UNION

`UNION`은 두 SELECT문의 결과를 하나로 합친다.

```sql
SELECT 컬럼명
FROM 테이블명

UNION

SELECT 컬럼명
FROM 테이블명;
```

### 특징

- 두 SELECT문의 결과를 하나로 결합한다.
- **중복되는 행은 제거**한다.

### 예시

학생과 교수의 소속 학과번호를 중복 없이 조회한다.

```sql
SELECT department_id
FROM students

UNION

SELECT department_id
FROM professors;
```

학생과 교수의 이름과 소속 학과번호를 하나의 목록으로 조회할 수도 있다.

```sql
SELECT name, department_id
FROM students

UNION

SELECT name, department_id
FROM professors;
```

---

## 2. UNION ALL

`UNION ALL`은 `UNION`과 마찬가지로 두 SELECT문의 결과를 합치지만 **중복되는 행을 제거하지 않는다.**

```sql
SELECT department_id
FROM students

UNION ALL

SELECT department_id
FROM professors;
```

### UNION과 UNION ALL 비교

| 연산자 | 중복 데이터 |
|---|---|
| `UNION` | 제거 |
| `UNION ALL` | 유지 |

중복 데이터가 존재하더라도 모든 결과를 확인하려면 `UNION ALL`을 사용한다.

---

## 3. INTERSECT

`INTERSECT`는 두 SELECT문의 결과에 **공통으로 존재하는 행만 조회**한다.

즉, 두 결과의 **교집합**을 구한다.

```sql
SELECT 컬럼명
FROM 테이블명

INTERSECT

SELECT 컬럼명
FROM 테이블명;
```

### 예시

학생과 교수 양쪽에 모두 존재하는 학과번호를 조회한다.

```sql
SELECT department_id
FROM students

INTERSECT

SELECT department_id
FROM professors;
```

> `INTERSECT`는 MariaDB 10.3 버전부터 지원된다.

---

## 4. EXCEPT

`EXCEPT`는 첫 번째 SELECT문의 결과에서 두 번째 SELECT문의 결과에 존재하는 행을 제외한다.

즉, 두 결과의 **차집합**을 구한다.

```sql
SELECT 컬럼명
FROM 테이블명

EXCEPT

SELECT 컬럼명
FROM 테이블명;
```

### 예시

수강 신청을 하지 않은 학생의 학번을 조회한다.

```sql
SELECT id
FROM students

EXCEPT

SELECT student_id
FROM enrollments;
```

첫 번째 조회 결과인 전체 학생의 학번에서  
수강 테이블에 존재하는 학생의 학번을 제외하는 방식이다.

> `EXCEPT`는 MariaDB 10.3 버전부터 지원된다.

---

## 핵심 정리

| 연산자 | 의미 | 중복 처리 |
|---|---|---|
| `UNION` | 합집합 | 중복 제거 |
| `UNION ALL` | 합집합 | 중복 유지 |
| `INTERSECT` | 교집합 | 공통 데이터 조회 |
| `EXCEPT` | 차집합 | 두 번째 결과에 있는 데이터 제외 |

쉽게 기억하면:

```text
UNION       → 합치기 + 중복 제거
UNION ALL   → 전부 합치기
INTERSECT   → 공통된 것만
EXCEPT      → 첫 번째에서 두 번째 빼기
```

## 집합 연산자 사용 조건

두 SELECT문은 다음 조건을 만족해야 한다.

```text
컬럼 개수 동일
+
대응되는 컬럼의 데이터 타입 호환
```

예를 들어 다음처럼 서로 대응되는 값을 조회해야 한다.

```sql
SELECT name, department_id
FROM students

UNION

SELECT name, department_id
FROM professors;
```

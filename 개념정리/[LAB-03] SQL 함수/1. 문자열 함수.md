# 문자열 함수

SQL 함수는 데이터를 조회하면서 **변환, 가공, 계산**하기 위해 사용한다.

## 함수의 종류

- **단일 행 함수** : 각 행마다 함수를 적용하여 하나의 결과를 반환
- **집계 함수** : 여러 행을 하나의 결과로 요약
  - `COUNT()`, `SUM()`, `AVG()`, `MAX()`, `MIN()` 등

---

## UPPER()

`UPPER()`는 문자열을 **대문자**로 변환한다.

```sql
UPPER(str)
```

### 대문자로 변환

급여가 500만원 이상인 교수의 아이디를 대문자로 출력한다.

```sql
SELECT UPPER(user_id)
FROM professors
WHERE sal >= 500
ORDER BY sal ASC;
```

---

## LOWER()

`LOWER()`는 문자열을 **소문자**로 변환한다.

```sql
LOWER(str)
```

### 소문자로 변환

이메일이 등록된 학과의 이메일 주소를 소문자로 출력한다.

```sql
SELECT LOWER(email)
FROM departments
WHERE email IS NOT NULL;
```

---

## CHAR_LENGTH()

`CHAR_LENGTH()`는 문자열의 **문자 수(글자 수)**를 반환한다.

```sql
CHAR_LENGTH(str)
```

### 문자열의 길이 구하기

학과 이름이 5글자를 초과하는 학과를 조회하고, 이름이 긴 순서대로 정렬한다.

```sql
SELECT dname,
       CHAR_LENGTH(dname) AS dname_len
FROM departments
WHERE CHAR_LENGTH(dname) > 5
ORDER BY dname_len DESC;
```

`SELECT`에서 지정한 별칭(alias)은 `ORDER BY`에서 사용할 수 있다.

## CONCAT()

`CONCAT()`은 여러 문자열을 **하나의 문자열로 연결**한다.

```sql
CONCAT(str1, str2, ...)
```

문자열뿐만 아니라 숫자도 연결할 수 있다.

### 문자열 연결하기

과목명과 학점을 `과목명(학점)` 형태로 출력한다.

```sql
SELECT name,
       credit,
       CONCAT(name, '(', credit, ')') AS subject_info
FROM subjects
WHERE credit = 1
ORDER BY subject_info ASC;
```

결과 예시:

```text
금융의 이해(1)
사진학개론(1)
심리학개론(1)
연극윤리(1)
```

## SUBSTRING()

`SUBSTRING()`은 문자열의 특정 위치부터 원하는 길이만큼 **문자를 추출**한다.

```sql
SUBSTRING(str, pos, len)
```

- `str` : 대상 문자열
- `pos` : 시작 위치
- `len` : 추출할 문자 수

문자열의 위치는 **1부터 시작**한다.

### 문자열의 일부 추출하기

이메일 주소의 2번째 문자부터 4글자를 추출한다.

```sql
SELECT email,
       SUBSTRING(email, 2, 4) AS part_email
FROM departments
WHERE email IS NOT NULL
ORDER BY part_email ASC;
```

예를 들어,

```sql
SELECT SUBSTRING('abcdef', 2, 3);
```

결과:

```text
bcd
```

세 번째 인자인 `len`은 **끝 위치가 아니라 추출할 글자 수**이다.

## LEFT() / RIGHT()

문자열의 왼쪽 또는 오른쪽에서 원하는 글자 수만큼 추출할 때 사용한다.

### LEFT()

`LEFT()`는 문자열의 **왼쪽부터 n글자**를 추출한다.

```sql
LEFT(str, n)
```

### RIGHT()

`RIGHT()`는 문자열의 **오른쪽부터 n글자**를 추출한다.

```sql
RIGHT(str, n)
```

### 왼쪽과 오른쪽에서 문자열 추출하기

교수의 성과 이름을 분리하여 출력한다.

```sql
SELECT LEFT(name, 1) AS 성,
       RIGHT(name, 2) AS 이름,
       position
FROM professors
WHERE position = '부교수';
```

예:

```sql
SELECT LEFT('abcdef', 3);
-- abc

SELECT RIGHT('abcdef', 2);
-- ef
```

## TRIM()

`TRIM()`은 문자열의 **앞뒤 공백을 제거**한다.

```sql
TRIM(str)
```

### 앞뒤 공백 제거하기

직급이 부교수인 교수 이름의 앞뒤 공백을 제거한다.

```sql
SELECT TRIM(name)
FROM professors
WHERE position = '부교수';
```

문자열 **중간에 있는 공백은 제거하지 않는다.**

```text
'  hello  ' → 'hello'
'hel lo'    → 'hel lo'
```

## REPLACE()

`REPLACE()`는 문자열에서 특정 문자열을 찾아 **다른 문자열로 변경**한다.

```sql
REPLACE(str, from, to)
```

- `str` : 대상 문자열
- `from` : 찾을 문자열
- `to` : 변경할 문자열

### 특정 문자열 변경하기

102번 학과 교수 이름의 `이`를 `LEE`로 변경한다.

```sql
SELECT REPLACE(name, '이', 'LEE')
FROM professors
WHERE department_id = 102;
```

예:

```sql
SELECT REPLACE('banana', 'na', 'ny');
```

결과:

```text
bannya
```

## INSTR()

`INSTR()`은 문자열 안에서 특정 문자열이 등장하는 **위치**를 반환한다.

```sql
INSTR(str, substr)
```

- 문자열의 위치는 **1부터 시작**
- 찾는 문자열이 존재하지 않으면 **0을 반환**

### 특정 문자열의 위치 찾기

이메일 주소에 `gmail.com`이 포함된 교수를 조회한다.

```sql
SELECT name, email
FROM professors
WHERE INSTR(email, 'gmail.com') > 0;
```

예:

```sql
SELECT INSTR('apple', 'l');
```

결과:

```text
4
```

`LIKE`를 사용하지 않고도 특정 문자열이 포함되어 있는지 확인할 수 있다.

## LPAD() / RPAD()

문자열을 지정한 길이까지 특정 문자로 채운다.

### LPAD()

`LPAD()`는 문자열의 **왼쪽**을 지정한 문자로 채운다.

```sql
LPAD(str, len, pad_str)
```

### RPAD()

`RPAD()`는 문자열의 **오른쪽**을 지정한 문자로 채운다.

```sql
RPAD(str, len, pad_str)
```

### 문자열 길이 맞추기

```sql
SELECT LPAD('12', 5, '0');
```

결과:

```text
00012
```

`len`은 추가할 문자의 개수가 아니라 **완성된 문자열의 전체 길이**이다.

### LPAD와 RPAD 함께 사용하기

교수 번호는 5자리로 만들고 왼쪽을 `0`으로 채운다.  
교수 이름은 10자리로 만들고 오른쪽을 공백으로 채운다.

```sql
SELECT CONCAT(
           '[',
           LPAD(id, 5, '0'),
           '] ',
           RPAD(name, 10, ' ')
       ) AS label
FROM professors
WHERE department_id = 101
ORDER BY label ASC;
```

## FORMAT()

`FORMAT()`은 숫자를 **천 단위 쉼표와 지정한 소수점 자리수** 형태로 출력한다.

```sql
FORMAT(number, n)
```

- `number` : 변환할 숫자
- `n` : 표시할 소수점 자리 수

### 숫자 형식 변경하기

교수 급여를 원 단위로 변환하고 천 단위 쉼표와 소수점 2자리를 표시한다.

```sql
SELECT name,
       FORMAT(sal * 10000, 2) AS formatted_salary
FROM professors
ORDER BY formatted_salary DESC
LIMIT 0, 5;
```

예:

```sql
SELECT FORMAT(12345, 2);
```

결과:

```text
12,345.00
```

## 핵심 정리

### SUBSTRING의 위치는 1부터 시작

```sql
SUBSTRING('abcdef', 2, 3)
-- bcd
```

- `2` : 시작 위치
- `3` : 끝 위치가 아니라 **가져올 글자 수**

### INSTR은 문자열이 없으면 0 반환

```sql
INSTR('apple', 'l')
-- 4

INSTR('apple', 'z')
-- 0
```

따라서 문자열 포함 여부를 확인할 때 다음과 같이 사용할 수 있다.

```sql
WHERE INSTR(email, 'gmail.com') > 0
```

### LPAD / RPAD의 len은 최종 길이

```sql
LPAD('12', 5, '0')
-- 00012
```

`0`을 5개 추가하는 것이 아니라 **전체 길이를 5로 맞춘다.**

### 별칭은 ORDER BY에서 사용 가능

```sql
SELECT dname,
       CHAR_LENGTH(dname) AS dname_len
FROM departments
ORDER BY dname_len DESC;
```

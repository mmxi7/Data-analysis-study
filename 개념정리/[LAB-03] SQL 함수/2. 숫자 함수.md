# 숫자 함수

숫자 함수는 숫자 데이터를 **계산하거나 원하는 형태로 변환**할 때 사용한다.

---

## ABS()

`ABS()`는 숫자의 **절댓값**을 반환한다.

```sql
ABS(x)
```

음수는 양수로 변환되고, 양수는 그대로 반환된다.

### 기준값과의 차이 구하기

학생의 평균 키를 170이라고 가정하고, 4학년 학생 중 키가 큰 상위 5명의 이름, 키, 기준 키와의 차이를 절댓값으로 조회한다.

```sql
SELECT name,
       height,
       ABS(height - 170) AS 키차이
FROM students
WHERE grade = 4
ORDER BY height DESC
LIMIT 0, 5;
```

예:

```sql
SELECT ABS(-5);
-- 5
```

## POWER()

`POWER()`는 숫자의 **제곱값**을 계산한다.

```sql
POWER(x, y)
```

`x`를 `y`번 곱한 값을 반환한다.

### 제곱값 계산하기

BMI 계산에서 키의 제곱값을 구할 때 사용할 수 있다.

```sql
POWER(height / 100, 2)
```

예:

```sql
SELECT POWER(2, 3);
-- 8
```

## ROUND()

`ROUND()`는 숫자를 지정한 소수점 자리까지 **반올림**한다.

```sql
ROUND(x, y)
```

- `x` : 반올림할 숫자
- `y` : 표시할 소수점 자리 수

### BMI 반올림하기

1학년 학생들의 이름, 키, 몸무게와 BMI를 소수점 둘째 자리까지 반올림하여 BMI의 오름차순으로 조회한다.

```sql
SELECT name,
       weight,
       height,
       ROUND(weight / POWER(height / 100, 2), 2) AS BMI
FROM students
WHERE grade = 1
ORDER BY BMI ASC;
```

예:

```sql
SELECT ROUND(3.1415, 2);
-- 3.14
```

---

## CEIL()

`CEIL()`은 숫자의 소수점 이하를 **올림**하여 정수로 반환한다.

```sql
CEIL(x)
```

예:

```sql
SELECT CEIL(3.2);
-- 4
```

---

## FLOOR()

`FLOOR()`는 숫자의 소수점 이하를 **내림**하여 정수로 반환한다.

```sql
FLOOR(x)
```

예:

```sql
SELECT FLOOR(3.8);
-- 3
```

---

## TRUNCATE()

`TRUNCATE()`는 숫자를 지정한 소수점 자리에서 **잘라낸다.**

```sql
TRUNCATE(x, y)
```

- `x` : 자를 숫자
- `y` : 남길 소수점 자리 수

반올림하지 않고 지정한 자리 이후의 값을 그대로 버린다.

예:

```sql
SELECT TRUNCATE(3.1415, 2);
-- 3.14
```

---

## CEIL() / FLOOR() / TRUNCATE() 비교

2학년 학생들의 BMI를 각각 올림, 내림, 소수점 셋째 자리까지 잘라서 조회한다.

```sql
SELECT name,
       weight,
       height,
       CEIL(weight / POWER(height / 100, 2)) AS BMI_UP,
       FLOOR(weight / POWER(height / 100, 2)) AS BMI_DOWN,
       TRUNCATE(weight / POWER(height / 100, 2), 3) AS BMI_TRUN
FROM students
WHERE grade = 2
ORDER BY name ASC;
```

| 함수 | 처리 방식 | 예시 |
|---|---|---|
| `ROUND(3.8)` | 반올림 | `4` |
| `CEIL(3.2)` | 올림 | `4` |
| `FLOOR(3.8)` | 내림 | `3` |
| `TRUNCATE(3.1415, 2)` | 지정한 자리에서 자름 | `3.14` |

## MOD()

`MOD()`는 숫자를 나눈 후 **나머지**를 반환한다.

```sql
MOD(x, y)
```

`x`를 `y`로 나눈 나머지를 구한다.

### 짝수 학년 조회하기

짝수 학년인 학생 중 몸무게가 가장 많이 나가는 상위 3명을 조회한다.

```sql
SELECT name,
       grade,
       gender,
       height,
       weight,
       phone
FROM students
WHERE MOD(grade, 2) = 0
ORDER BY weight DESC
LIMIT 0, 3;
```

예:

```sql
SELECT MOD(10, 3);
-- 1
```

## SIGN()

`SIGN()`은 숫자가 양수인지, 0인지, 음수인지에 따라 값을 반환한다.

```sql
SIGN(x)
```

| 조건 | 반환값 |
|---|---:|
| `x > 0` | `1` |
| `x = 0` | `0` |
| `x < 0` | `-1` |

### 기준값과 비교하기

1학년 남학생의 키가 평균 키 170보다 큰지 작은지를 확인한다.

```sql
SELECT name,
       SIGN(height - 170) AS 평균비교
FROM students
WHERE grade = 1
  AND gender = '남'
ORDER BY height DESC;
```

- `1` : 평균보다 큼
- `0` : 평균과 같음
- `-1` : 평균보다 작음

| `ROUND()` | 지정한 소수점 자리까지 반올림 |
| `CEIL()` | 소수점 이하 올림 |
| `FLOOR()` | 소수점 이하 내림 |
| `TRUNCATE()` | 지정한 소수점 자리에서 자름 |
| `MOD()` | 나눗셈의 나머지 반환 |
| `SIGN()` | 양수, 0, 음수 판별 |

## 핵심 정리

### ROUND와 TRUNCATE의 차이

`ROUND()`는 **반올림**하고, `TRUNCATE()`는 **그대로 잘라낸다.**

```sql
ROUND(3.1415, 2)
-- 3.14

TRUNCATE(3.1415, 2)
-- 3.14
```

차이가 더 잘 보이는 값으로 비교하면 다음과 같다.

```sql
ROUND(3.146, 2)
-- 3.15

TRUNCATE(3.146, 2)
-- 3.14
```

### CEIL과 FLOOR

```sql
CEIL(3.2)
-- 4

FLOOR(3.8)
-- 3
```

- `CEIL()` : 소수점 이하 **올림**
- `FLOOR()` : 소수점 이하 **내림**

### ABS는 기준값과의 차이를 구할 때 활용 가능

```sql
ABS(height - 170)
```

170보다 크거나 작아도 항상 양수인 **거리(차이)**를 구할 수 있다.

### MOD로 짝수와 홀수를 구분할 수 있음

```sql
MOD(grade, 2) = 0
```

2로 나눈 나머지가 `0`이면 짝수이다.

### SIGN의 반환값

```sql
SIGN(height - 170)
```

- 양수 → `1`
- 0 → `0`
- 음수 → `-1`

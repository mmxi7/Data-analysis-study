# 날짜·시간 함수

날짜·시간 함수는 **현재 날짜와 시간을 조회하거나, 날짜/시간 타입의 값을 추출·계산·변환**할 때 사용한다.

---

## NOW() / CURDATE() / CURTIME()

현재 날짜와 시간을 조회할 때 사용한다.

### NOW()

현재 **날짜와 시간**을 반환한다.

```sql
NOW()
```

### CURDATE()

현재 **날짜**를 반환한다.

```sql
CURDATE()
```

### CURTIME()

현재 **시간**을 반환한다.

```sql
CURTIME()
```

### 현재 날짜와 시간 조회하기

```sql
SELECT NOW() AS 현재_날짜시간,
       CURDATE() AS 오늘_날짜,
       CURTIME() AS 현재_시간;
```

이 함수들은 테이블에서 데이터를 가져오는 것이 아니라 함수를 직접 실행하여 결과를 반환하므로 `FROM`절이 없어도 된다.

---

## DATE() / TIME()

날짜와 시간이 함께 저장된 값에서 날짜 또는 시간만 추출한다.

### DATE()

날짜/시간 값에서 **날짜 부분**만 추출한다.

```sql
DATE(datetime)
```

### TIME()

날짜/시간 값에서 **시간 부분**만 추출한다.

```sql
TIME(datetime)
```

### 날짜와 시간 분리하기

202번 학과에 소속된 교수의 입사일에서 날짜와 시간 부분을 따로 조회한다.

```sql
SELECT name,
       hiredate,
       DATE(hiredate) AS 날짜,
       TIME(hiredate) AS 시간
FROM professors
WHERE department_id = 202;
```

예:

```text
DATE('2025-04-05 10:30:00') → 2025-04-05
TIME('2025-04-05 10:30:00') → 10:30:00
```

---

## YEAR() / MONTH() / DAY()

날짜에서 연도, 월, 일을 각각 추출한다.

### YEAR()

날짜에서 **연도**를 추출한다.

```sql
YEAR(datetime)
```

### MONTH()

날짜에서 **월**을 추출한다.

```sql
MONTH(datetime)
```

### DAY()

날짜에서 **일**을 추출한다.

```sql
DAY(datetime)
```

### 연도, 월, 일 분리하기

402번 학과에 소속된 교수의 이름, 입사년도, 입사월, 입사일을 조회한다.

```sql
SELECT name,
       YEAR(hiredate) AS 입사년도,
       MONTH(hiredate) AS 입사월,
       DAY(hiredate) AS 입사일
FROM professors
WHERE department_id = 402;
```

---

## DATE_ADD()

날짜에 일정 기간을 **더한다.**

```sql
DATE_ADD(date, INTERVAL n unit)
```

`INTERVAL`은 날짜에 더하거나 뺄 **기간**을 지정한다.

### 날짜에 기간 더하기

수강신청 당일부터 1주일간 수정신청이 가능하다고 할 때 수정 마감일을 계산한다.

```sql
SELECT student_id,
       subject_id,
       enroll_date,
       DATE_ADD(enroll_date, INTERVAL 7 DAY) AS '수강신청 정정 마감일'
FROM enrollments
WHERE student_id = 10105;
```

`n`에 음수를 사용하면 기간을 빼는 효과가 있다.

---

## DATE_SUB()

날짜에서 일정 기간을 **뺀다.**

```sql
DATE_SUB(date, INTERVAL n unit)
```

### 날짜에서 기간 빼기

졸업일로부터 1개월 전부터 졸업 가운 대여 신청이 가능하다고 할 때 신청 시작 날짜를 조회한다.

```sql
SELECT name,
       DATE_SUB(graduation_date, INTERVAL 1 MONTH) AS '대여 시작일'
FROM students
WHERE graduation_date IS NOT NULL;
```

`n`에 음수를 사용하면 기간을 더하는 효과가 있다.

---

## INTERVAL의 단위

`DATE_ADD()`와 `DATE_SUB()`에서 연산할 기간의 단위를 지정할 때 사용한다.

| 단위 | 의미 | 예시 |
|---|---|---|
| `SECOND` | 초 | `INTERVAL 30 SECOND` |
| `MINUTE` | 분 | `INTERVAL -10 MINUTE` |
| `HOUR` | 시간 | `INTERVAL 2 HOUR` |
| `DAY` | 일 | `INTERVAL -7 DAY` |
| `WEEK` | 주 | `INTERVAL 1 WEEK` |
| `MONTH` | 월 | `INTERVAL -1 MONTH` |
| `QUARTER` | 분기(3개월) | `INTERVAL 1 QUARTER` |
| `YEAR` | 년 | `INTERVAL -1 YEAR` |

예:

```sql
DATE_ADD(date, INTERVAL 7 DAY)
```

→ 날짜에 **7일을 더한다.**

```sql
DATE_SUB(date, INTERVAL 1 MONTH)
```

→ 날짜에서 **1개월을 뺀다.**

---

## DATEDIFF()

두 날짜 사이의 **일(day) 차이**를 계산한다.

```sql
DATEDIFF(date1, date2)
```

계산 방식:

```text
date1 - date2
```

### 근속일수 계산하기

301번 학과에서 현재까지 휴직하지 않고 재직 중인 교수의 이름, 직급, 입사일, 근속일수를 근속일수가 오래된 순서대로 조회한다.

```sql
SELECT name,
       position,
       hiredate,
       DATEDIFF(CURDATE(), hiredate) AS 근속일수
FROM professors
WHERE department_id = 301
ORDER BY 근속일수 DESC;
```

`date1`이 더 최신 날짜여야 양수 결과가 나온다.

## DATE_FORMAT()

날짜를 원하는 **문자열 형식으로 변환**한다.

```sql
DATE_FORMAT(date, format)
```

### 날짜 형식 변경하기

301번 학과 교수의 입사일을 `YYYY년 MM월 DD일` 형식으로 출력한다.

```sql
SELECT name,
       DATE_FORMAT(hiredate, '%Y년 %m월 %d일') AS 입사일
FROM professors
WHERE department_id = 301;
```

예:

```text
2002년 12월 03일
2005년 01월 30일
```

---

## DATE_FORMAT의 주요 형식 문자

| 기능 | 형식 문자 | 기능 | 형식 문자 |
|---|---|---|---|
| 달 이름 | `%M` | MM 형식의 월 | `%m` |
| 요일 이름 | `%W` | 24시간제 시간 | `%H` |
| YYYY 형식의 년도 | `%Y` | 24시간제 시간 | `%k` |
| YY 형식의 년도 | `%y` | 12시간제 시간 | `%h` |
| 요일 이름의 약자 | `%a` | MM 형식의 분 | `%i` |
| DD 형식의 날짜 | `%d` | SS 형식의 초 | `%s` |
| D 형식의 날짜 | `%e` | AM/PM | `%p` |

### 날짜와 시간 형식 만들기

```sql
SELECT DATE_FORMAT(
    NOW(),
    '%y/%m/%d %H:%i:%s'
);
```

---

## DATE_FORMAT을 조건으로 사용하기

`DATE_FORMAT()`은 `SELECT`뿐만 아니라 `WHERE`의 조건에서도 활용할 수 있다.

2024년 7월 혹은 8월에 입학한 학생을 조회한다.

```sql
SELECT name,
       grade,
       gender,
       status,
       admission_date
FROM students
WHERE DATE_FORMAT(admission_date, '%Y') = 2024
  AND DATE_FORMAT(admission_date, '%m') IN (7, 8)
ORDER BY admission_date ASC;
```

## QUARTER()

지정한 날짜가 몇 분기인지 **1~4 사이의 값**으로 반환한다.

```sql
QUARTER(date)
```

| 반환값 | 분기 |
|---|---|
| `1` | 1분기 |
| `2` | 2분기 |
| `3` | 3분기 |
| `4` | 4분기 |

### 입사 분기 조회하기

202번 학과 교수들의 이름과 직급, 입사한 분기를 조회한다.

```sql
SELECT name,
       position,
       QUARTER(hiredate) AS 분기
FROM professors
WHERE department_id = 202
ORDER BY 분기 ASC;
```

## 날짜·시간 함수 한눈에 보기

| 함수 | 기능 |
|---|---|
| `NOW()` | 현재 날짜와 시간 반환 |
| `CURDATE()` | 현재 날짜 반환 |
| `CURTIME()` | 현재 시간 반환 |
| `DATE()` | 날짜/시간 값에서 날짜 추출 |
| `TIME()` | 날짜/시간 값에서 시간 추출 |
| `YEAR()` | 연도 추출 |
| `MONTH()` | 월 추출 |
| `DAY()` | 일 추출 |
| `DATE_ADD()` | 날짜에 일정 기간 추가 |
| `DATE_SUB()` | 날짜에서 일정 기간 차감 |
| `DATEDIFF()` | 두 날짜의 차이를 일(day) 단위로 계산 |
| `DATE_FORMAT()` | 날짜를 원하는 문자열 형식으로 변환 |
| `QUARTER()` | 날짜가 속한 분기 반환 |

## 핵심 정리

### 현재 날짜와 시간

```sql
NOW()       -- 현재 날짜 + 시간
CURDATE()   -- 현재 날짜
CURTIME()   -- 현재 시간
```

### 날짜에서 원하는 부분 추출

```sql
DATE(datetime)    -- 날짜
TIME(datetime)    -- 시간
YEAR(datetime)    -- 연도
MONTH(datetime)   -- 월
DAY(datetime)     -- 일
```

### 날짜에 기간 더하기 / 빼기

```sql
DATE_ADD(date, INTERVAL 7 DAY)
DATE_SUB(date, INTERVAL 1 MONTH)
```

`INTERVAL`은 연산할 **기간과 단위**를 지정한다.

### 두 날짜의 차이

```sql
DATEDIFF(date1, date2)
```

`date1 - date2`의 일(day) 차이를 반환한다.

### 날짜 형식 변경

```sql
DATE_FORMAT(date, '%Y년 %m월 %d일')
```

### 분기 구하기

```sql
QUARTER(date)
```

날짜가 속한 분기를 `1~4` 사이의 값으로 반환한다.

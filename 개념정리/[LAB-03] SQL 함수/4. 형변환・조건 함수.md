# 형변환·조건 함수

## CAST()

값을 지정한 데이터 타입으로 변환하는 함수입니다.

```sql
CAST(expr AS type)
```

### 문자열을 정수로 변환

문자열 `'1500'`을 정수로 변환한 뒤 2를 곱합니다.

```sql
SELECT CAST('1500' AS INT) * 2 AS 두배정수;
```

결과:

```text
3000
```

### 문자열을 날짜로 변환

```sql
SELECT CAST('2025-05-01' AS DATE) AS 날짜변환;
```

---

## CONVERT()

`CAST()`와 동일하게 값을 지정한 데이터 타입으로 변환하는 함수입니다.

```sql
CONVERT(expr, type)
```

### 문자열을 정수로 변환

```sql
SELECT CONVERT('1500', INT) * 2 AS 두배정수;
```

### 문자열을 날짜로 변환

```sql
SELECT CONVERT('2025-05-01', DATE) AS 날짜변환;
```

---

## 형변환 함수와 날짜 함수 활용

문자열 형태의 날짜를 `DATE` 타입으로 변환한 뒤 날짜 함수와 함께 사용할 수 있습니다.

### 문자열 날짜의 100일 후 계산

```sql
SELECT DATE_FORMAT(
           DATE_ADD(CAST('2025-05-01' AS DATE), INTERVAL 100 DAY),
           '%y/%m/%d'
       ) AS 100일후;
```

`CONVERT()`를 사용해도 동일하게 처리할 수 있습니다.

```sql
SELECT DATE_FORMAT(
           DATE_ADD(CONVERT('2025-05-01', DATE), INTERVAL 100 DAY),
           '%y/%m/%d'
       ) AS 100일후;
```

결과:

```text
25/08/09
```

## IF()

조건이 참인지 거짓인지에 따라 서로 다른 값을 반환하는 함수입니다.

```sql
IF(조건, 참일 때 값, 거짓일 때 값)
```

### 키에 따라 구분

키가 170cm 이상이면 `'장신'`, 그렇지 않으면 `'보통'`으로 표시합니다.

```sql
SELECT name, height,
       IF(height >= 170, '장신', '보통') AS '키 구분'
FROM students;
```

### 보직수당에 따라 임금 계산

보직수당이 있으면 급여에 보직수당을 더하고, 보직수당이 없으면 급여에 100을 더합니다.

```sql
SELECT name,
       sal + IF(comm IS NOT NULL, comm, 100) AS 임금
FROM professors;
```

## IFNULL()

검사할 값이 `NULL`이면 대체 값을 반환하고, `NULL`이 아니면 원래 값을 반환하는 함수입니다.

```sql
IFNULL(검사할 값, NULL일 경우 대체할 값)
```

### NULL인 점수 처리

점수가 입력되지 않은 경우 `'미입력'`으로 표시합니다.

```sql
SELECT student_id, subject_id,
       IFNULL(score, '미입력') AS 성적
FROM enrollments;
```

### 0으로 나누는 오류 방지

보직수당이 없거나 0이면 0을 반환하고, 그렇지 않으면 급여를 보직수당으로 나눕니다.

```sql
SELECT name, sal, comm,
       IF(IFNULL(comm, 0) = 0, 0, sal / comm) AS '수당 1포인트당 급여'
FROM professors;
```

## NULLIF()

두 표현식을 비교하여 값이 같으면 `NULL`을 반환하고, 값이 다르면 첫 번째 표현식의 값을 반환하는 함수입니다.

```sql
NULLIF(표현식1, 표현식2)
```

### 특정 상태를 NULL로 변환

학생의 상태가 `'재학'`이면 `NULL`로 표시하고, 그 외의 상태는 원래 값을 그대로 출력합니다.

```sql
SELECT name,
       NULLIF(status, '재학') AS 상태
FROM students
ORDER BY name ASC;
```

동작 방식:

```text
status = '재학' → NULL
status = '휴학' → '휴학'
status = '졸업' → '졸업'
status = '퇴학' → '퇴학'
```

## CASE 문

`IF()`보다 복잡한 여러 조건을 순서대로 처리할 때 사용하는 구문입니다.

```sql
CASE
    WHEN 조건1 THEN 결과1
    WHEN 조건2 THEN 결과2
    ...
    ELSE 결과
END
```

- `WHEN 조건 THEN 결과` : 조건이 참이면 해당 결과를 반환합니다.
- 여러 `WHEN` 조건은 위에서부터 순서대로 확인합니다.
- `ELSE` : 앞의 모든 `WHEN` 조건이 거짓일 때 반환할 값을 지정합니다.
- `END` : `CASE` 문의 끝을 나타냅니다.

### 몸무게에 따라 체급 분류

- 80kg 이상 → `헤비급`
- 60kg 이상 80kg 미만 → `미들급`
- 60kg 미만 → `라이트급`

```sql
SELECT name, weight,
       CASE
           WHEN weight >= 80 THEN '헤비급'
           WHEN weight >= 60 THEN '미들급'
           ELSE '라이트급'
       END AS '체급 분류'
FROM students;
```

`CASE` 문은 위에서부터 조건을 검사하기 때문에 두 번째 조건을 다음과 같이 작성하지 않아도 됩니다.

```sql
WHEN weight >= 60 AND weight < 80
```

첫 번째 `WHEN weight >= 80`에서 이미 80kg 이상인 데이터가 처리되므로,

```sql
WHEN weight >= 60
```

만 작성해도 60kg 이상 80kg 미만인 데이터가 해당됩니다.

## 형변환 함수 한눈에 보기

| 함수 | 기능 |
|---|---|
| `CAST(expr AS type)` | 값을 지정한 데이터 타입으로 변환 |
| `CONVERT(expr, type)` | `CAST()`와 동일하게 값을 지정한 데이터 타입으로 변환 |

---

## 조건 함수 한눈에 보기

| 함수 | 기능 |
|---|---|
| `IF(조건, 참, 거짓)` | 조건이 참이면 두 번째 값, 거짓이면 세 번째 값 반환 |
| `IFNULL(값, 대체값)` | 값이 `NULL`이면 대체값 반환 |
| `NULLIF(값1, 값2)` | 두 값이 같으면 `NULL`, 다르면 첫 번째 값 반환 |
| `CASE` | 여러 조건을 순서대로 검사하여 결과 반환 |

---

## 핵심 정리

- `CAST()`와 `CONVERT()`는 데이터 타입을 변환할 때 사용합니다.
- `CAST()`는 `CAST(expr AS type)` 형식으로 사용합니다.
- `CONVERT()`는 `CONVERT(expr, type)` 형식으로 사용합니다.
- 문자열 형태의 날짜를 `DATE`로 변환한 뒤 `DATE_ADD()`, `DATE_FORMAT()` 등의 날짜 함수와 함께 사용할 수 있습니다.
- `IF()`는 하나의 조건에 따라 두 가지 결과 중 하나를 반환합니다.
- `IFNULL()`은 `NULL`을 다른 값으로 대체할 때 사용합니다.
- `NULLIF()`는 두 값이 같을 경우 `NULL`로 변환할 때 사용합니다.
- `CASE` 문은 여러 조건을 순서대로 처리할 때 사용합니다.
- `CASE` 문은 위에서부터 조건을 검사하므로 조건의 순서가 중요합니다.

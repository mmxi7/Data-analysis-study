# 집계 함수

여러 행의 데이터를 하나의 값으로 요약하여 계산할 때 사용하는 함수이다.

합계, 평균, 개수, 최댓값, 최솟값 등을 계산할 수 있다.

> 집계 함수는 `WHERE` 절에서 사용할 수 없다.

---

## COUNT()

데이터의 개수를 반환한다.

```sql
COUNT(컬럼)
```

### 전체 행 개수

`COUNT(*)`는 전체 행의 개수를 반환한다.

```sql
SELECT COUNT(*)
FROM departments;
```

### 특정 컬럼의 개수

`COUNT(컬럼)`은 해당 컬럼에서 `NULL`을 제외한 값의 개수를 반환한다.

```sql
SELECT COUNT(homepage)
FROM departments;
```

따라서 `COUNT(*)`와 `COUNT(컬럼)`의 결과는 `NULL` 값의 존재 여부에 따라 달라질 수 있다.

```sql
SELECT COUNT(*) AS '전체 학과',
       COUNT(homepage) AS '홈페이지 보유 학과'
FROM departments;
```

- `COUNT(*)` → 전체 학과 수
- `COUNT(homepage)` → 홈페이지 값이 `NULL`이 아닌 학과 수

### 조건에 해당하는 행 개수

```sql
SELECT COUNT(*) AS '총 교수 수',
       COUNT(comm) AS '보직수당 수령 교수 수'
FROM professors
WHERE status = '재직';
```

- `COUNT(*)` → 재직 상태인 모든 교수의 수
- `COUNT(comm)` → 재직 교수 중 `comm`이 `NULL`이 아닌 교수의 수

## SUM()

`NULL` 값을 제외한 숫자 데이터의 합계를 반환한다.

```sql
SUM(컬럼)
```

### 합계 계산

```sql
SELECT SUM(credit) AS '총 학점'
FROM subjects;
```

### 여러 컬럼의 합계 계산

```sql
SELECT SUM(sal) AS '총 급여',
       SUM(comm) AS '총 보직수당',
       SUM(sal) + SUM(comm) AS '총 임금'
FROM professors;
```

`SUM()`은 `NULL` 값을 제외하고 계산하기 때문에 `comm`이 `NULL`인 데이터는 보직수당 합계에서 제외된다.

---

## AVG()

`NULL` 값을 제외한 숫자 데이터의 평균을 반환한다.

```sql
AVG(컬럼)
```

### 평균 계산

```sql
SELECT ROUND(AVG(height), 1) AS '평균키',
       ROUND(AVG(weight), 1) AS '평균몸무게'
FROM students;
```

`ROUND()`와 함께 사용하여 원하는 소수점 자리까지 반올림할 수 있다.

### 여러 컬럼의 평균 계산

```sql
SELECT AVG(sal) AS '평균급여',
       AVG(comm) AS '평균보직수당',
       AVG(sal) + AVG(comm) AS '평균임금'
FROM professors;
```

`AVG()` 역시 `NULL` 값을 제외하고 계산한다.

---

## MAX()

`NULL` 값을 제외한 데이터 중 최댓값을 반환한다.

```sql
MAX(컬럼)
```

```sql
SELECT MAX(score) AS 최고성적
FROM enrollments;
```

---

## MIN()

`NULL` 값을 제외한 데이터 중 최솟값을 반환한다.

```sql
MIN(컬럼)
```

```sql
SELECT MIN(score) AS 최저성적
FROM enrollments;
```

### MAX()와 MIN() 함께 사용

```sql
SELECT MAX(score) AS 최고성적,
       MIN(score) AS 최저성적
FROM enrollments;
```

### 최댓값과 최솟값의 차이

```sql
SELECT MAX(sal) AS 최댓값,
       MIN(sal) AS 최솟값,
       MAX(sal) - MIN(sal) AS '임금격차'
FROM professors;
```

최댓값에서 최솟값을 빼면 데이터의 범위를 구할 수 있다.

---

## GROUP_CONCAT()

여러 행의 문자열 값을 하나의 문자열로 결합하여 반환한다.

```sql
GROUP_CONCAT(컬럼)
```

`NULL` 값은 제외되며, 여러 값은 쉼표(`,`)로 구분된다.

### 여러 행의 문자열 결합

```sql
SELECT GROUP_CONCAT(dname)
FROM departments
WHERE loc = '공학관';
```

공학관에 위치한 여러 학과의 이름을 하나의 문자열로 결합한다.

```text
컴퓨터공학과,전자공학과,기계공학과
```

### 조건에 해당하는 문자열 결합

```sql
SELECT GROUP_CONCAT(name)
FROM professors
WHERE status = '휴직';
```

휴직 중인 교수들의 이름을 하나의 문자열로 결합한다.

## 집계 함수 정리

| 함수 | 기능 | NULL 처리 |
|---|---|---|
| `COUNT(*)` | 전체 행의 개수 | NULL 여부와 관계없이 행 계산 |
| `COUNT(컬럼)` | 해당 컬럼의 값 개수 | NULL 제외 |
| `SUM()` | 합계 | NULL 제외 |
| `AVG()` | 평균 | NULL 제외 |
| `MAX()` | 최댓값 | NULL 제외 |
| `MIN()` | 최솟값 | NULL 제외 |
| `GROUP_CONCAT()` | 여러 값을 문자열로 결합 | NULL 제외 |

---

## 핵심 정리

- 집계 함수는 **여러 행을 하나의 값으로 요약**할 때 사용한다.
- `COUNT(*)`는 전체 행의 개수를 계산한다.
- `COUNT(컬럼)`은 해당 컬럼의 `NULL` 값을 제외하고 계산한다.
- `SUM()`은 숫자의 합계를 계산한다.
- `AVG()`는 숫자의 평균을 계산한다.
- `MAX()`는 최댓값을 반환한다.
- `MIN()`은 최솟값을 반환한다.
- `GROUP_CONCAT()`은 여러 행의 값을 하나의 문자열로 결합한다.
- 대부분의 집계 함수는 `NULL` 값을 제외하고 계산한다.
- 집계 함수는 `WHERE` 절에서 사용할 수 없다.

# GROUP BY

`GROUP BY`는 **기준 컬럼의 값이 같은 데이터끼리 하나의 그룹으로 묶는 기능**이다.

주로 그룹별 통계를 구하기 위해 **집계 함수와 함께 사용**한다.

## 기본 문법

```sql
SELECT 컬럼이름 [[AS] 컬럼별칭]
FROM 테이블이름
[WHERE 검색조건]
[GROUP BY 기준컬럼1, 기준컬럼2, ...]
[ORDER BY 정렬기준]
[LIMIT 시작위치, 개수];
```

- 기준 컬럼의 값이 같은 데이터끼리 하나의 그룹으로 묶는다.
- 기준 컬럼 값이 여러 개인 경우 첫 번째 기준으로 그룹화한 후, 그 안에서 두 번째 기준으로 다시 그룹을 나눈다.
- `SELECT` 절에서 지정한 별칭을 사용할 수 있다.
- `WHERE` 절은 그룹핑 전에 데이터를 필터링할 때 사용한다.
- `GROUP BY`에 명시하지 않은 컬럼은 집계 함수와 함께 사용해야 한다.

---

## GROUP BY와 집계 함수

`GROUP BY`는 그룹별 통계를 구하기 위해 `COUNT()`, `SUM()`, `AVG()` 등의 집계 함수와 함께 사용할 수 있다.

### 학과별 교수 수와 보직 수당을 받는 교수 수

```sql
SELECT department_id, COUNT(*), COUNT(comm)
FROM professors
GROUP BY department_id
ORDER BY department_id ASC;
```

- `department_id`를 기준으로 교수들을 그룹화한다.
- `COUNT(*)`는 각 학과의 전체 교수 수를 구한다.
- `COUNT(comm)`은 `comm` 값이 있는 교수의 수를 구한다.
- 집계 함수는 `NULL` 값을 제외하고 집계하므로 `COUNT(comm)`은 보직 수당 값이 저장된 교수만 계산한다.

---

## 여러 컬럼으로 그룹화

`GROUP BY`에는 여러 개의 기준 컬럼을 지정할 수 있다.

```sql
SELECT department_id, grade, COUNT(*), AVG(height), AVG(weight)
FROM students
GROUP BY department_id, grade
ORDER BY department_id ASC, grade ASC;
```

위 쿼리는 먼저 `department_id`를 기준으로 그룹화한 후, 같은 학과 안에서 다시 `grade`를 기준으로 그룹화한다.

즉,

```text
학과
 ├─ 1학년
 ├─ 2학년
 ├─ 3학년
 └─ 4학년
```

처럼 학과별 → 학년별로 그룹이 나뉜다.

---

## 함수의 결과를 기준으로 그룹화

컬럼에 함수를 적용한 결과를 기준으로 그룹화할 수도 있다.

### 연도별 교수 수

```sql
SELECT DATE_FORMAT(hiredate, '%Y') AS 년도, COUNT(*) AS '교수 수'
FROM professors
GROUP BY 년도
ORDER BY 년도 ASC;
```

또는 `YEAR()` 함수를 사용할 수 있다.

```sql
SELECT YEAR(hiredate) AS 년도, COUNT(*) AS '교수 수'
FROM professors
GROUP BY 년도
ORDER BY 년도 ASC;
```

`SELECT` 절에서 만든 `년도`라는 별칭을 `GROUP BY`와 `ORDER BY`에서 사용할 수 있다.

---

### 연도별·분기별 학생 수

```sql
SELECT DATE_FORMAT(admission_date, '%Y') AS 년도,
       QUARTER(admission_date) AS 분기,
       COUNT(*) AS 학생수
FROM students
WHERE DATE_FORMAT(admission_date, '%Y') = 2025
GROUP BY 년도, 분기;
```

`YEAR()` 함수를 이용하면 다음과 같이 작성할 수도 있다.

```sql
SELECT YEAR(admission_date) AS 년도,
       QUARTER(admission_date) AS 분기,
       COUNT(*) AS 학생수
FROM students
WHERE YEAR(admission_date) = 2025
GROUP BY 년도, 분기;
```

# HAVING

`HAVING`은 **그룹화된 결과에 조건을 지정할 때 사용하는 절**이다.

## 기본 문법

```sql
SELECT 컬럼이름 [[AS] 컬럼별칭]
FROM 테이블이름
[WHERE 검색조건]
[GROUP BY 기준컬럼1, 기준컬럼2, ...]
[HAVING 검색조건]
[ORDER BY 정렬기준]
[LIMIT 시작위치, 개수];
```

## WHERE와 HAVING의 차이

`WHERE`는 그룹화하기 **전의 데이터**에 조건을 지정하고,  
`HAVING`은 `GROUP BY`로 그룹화한 **결과**에 조건을 지정한다.

| 구분 | WHERE | HAVING |
| --- | --- | --- |
| 조건 적용 대상 | 그룹화 전 데이터 | 그룹화된 결과 |
| 집계 함수 조건 | 사용할 수 없음 | 사용할 수 있음 |
| GROUP BY 필요 여부 | 없어도 사용 가능 | GROUP BY와 함께 사용 |

집계 함수에 대한 조건을 지정해야 하는 경우 `HAVING`을 사용한다.

---

## HAVING 활용

### 학생 수가 5명을 초과하는 학과

```sql
SELECT department_id, COUNT(*) AS 학생수
FROM students
GROUP BY department_id
HAVING 학생수 > 5
ORDER BY 학생수 ASC;
```

`COUNT(*) AS 학생수`로 만든 별칭을 `HAVING`의 조건에서 사용할 수 있다.

---

### 입학생 수가 6~10명인 연도

```sql
SELECT DATE_FORMAT(admission_date, '%Y') AS 년도,
       COUNT(*) AS 학생수
FROM students
GROUP BY 년도
HAVING 학생수 >= 6 AND 학생수 <= 10
ORDER BY 년도 DESC;
```

`BETWEEN`을 이용하면 다음과 같이 작성할 수도 있다.

```sql
SELECT DATE_FORMAT(admission_date, '%Y') AS 년도,
       COUNT(*) AS 학생수
FROM students
GROUP BY 년도
HAVING 학생수 BETWEEN 6 AND 10
ORDER BY 년도 DESC;
```

# DISTINCT

`DISTINCT`는 **조회 결과에서 중복된 행을 제거할 때 사용하는 키워드**이다.

## 기본 문법

```sql
SELECT DISTINCT 컬럼이름
FROM 테이블이름;
```

- `SELECT` 키워드 뒤에 한 번만 작성한다.
- 각 컬럼 앞에 따로 작성하지 않는다.
- 값의 종류를 파악할 때 사용할 수 있다.

---

## 하나의 컬럼에서 중복 제거

### 교수의 직급 종류

```sql
SELECT DISTINCT position
FROM professors;
```

`DISTINCT`를 사용하지 않으면 모든 교수의 직급이 조회되므로 같은 직급이 여러 번 나타날 수 있다.

`DISTINCT`를 사용하면 중복된 직급이 제거되어 직급의 종류만 확인할 수 있다.

---

## 여러 컬럼에서 중복 제거

```sql
SELECT DISTINCT department_id, position
FROM professors
ORDER BY department_id;
```

여러 컬럼을 지정하면 **지정한 컬럼들의 값이 모두 같은 행**을 중복으로 판단하여 제거한다.

즉, 위 쿼리는 학과별로 존재하는 교수 직급의 종류를 조회한다.

---

## COUNT()와 DISTINCT

`DISTINCT`와 `COUNT()`를 함께 사용하면 중복을 제외한 값의 개수를 구할 수 있다.

### 교수 직급 종류의 개수

```sql
SELECT COUNT(DISTINCT position)
FROM professors;
```

`position`의 중복을 제거한 뒤 그 개수를 계산한다.

---

# 핵심 정리

| 기능 | 설명 |
| --- | --- |
| `GROUP BY` | 같은 값을 가진 데이터끼리 그룹화 |
| `COUNT()`, `SUM()`, `AVG()` 등 | 그룹별 집계값 계산 |
| `WHERE` | 그룹화하기 전 데이터에 조건 지정 |
| `HAVING` | 그룹화된 결과에 조건 지정 |
| `DISTINCT` | 조회 결과의 중복 제거 |
| `COUNT(DISTINCT 컬럼)` | 중복을 제외한 값의 개수 계산 |

### GROUP BY 처리 흐름

```text
FROM
 ↓
WHERE
 ↓
GROUP BY
 ↓
HAVING
 ↓
SELECT
 ↓
ORDER BY
 ↓
LIMIT
```

- `WHERE` : 그룹화하기 전에 필요한 행을 필터링
- `GROUP BY` : 같은 값을 가진 행을 그룹화
- `HAVING` : 만들어진 그룹에 조건 적용
- `SELECT` : 조회할 결과 결정
- `ORDER BY` : 결과 정렬
- `LIMIT` : 출력할 행의 범위 제한

> MariaDB에서는 `SELECT`에서 지정한 별칭을 `GROUP BY`, `HAVING`, `ORDER BY`에서 사용할 수 있다.

# 윈도우 함수

윈도우 함수(Window Function)는 **행과 행 간의 관계를 쉽게 정의하는 함수**이다.

정렬된 데이터의 특정 범위 안에서 **순위, 합계, 평균 등의 집계 작업**을 수행할 수 있다.

윈도우 함수는 `OVER()` 절과 함께 사용하며, `OVER()` 절 안에서 데이터를 그룹으로 나누거나 정렬할 수 있다.

```sql
윈도우함수() OVER (
    PARTITION BY 그룹_기준_필드
    ORDER BY 정렬_기준_필드 [ASC|DESC]
)
```

- `OVER()` : 윈도우 함수가 계산될 범위를 지정
- `PARTITION BY` : 데이터를 그룹으로 나누어 각 그룹 안에서 계산
- `ORDER BY` : 윈도우 안에서 데이터의 순서를 지정

---

## RANK()

`RANK()`는 특정 열의 값을 기준으로 **순위**를 계산하는 함수이다.

동일한 값을 가진 행이 여러 개라면 **같은 순위**를 부여하고, 그다음 순위는 동일한 순위의 행 개수만큼 건너뛴다.

예를 들어 2등이 2명이라면 다음 순위는 4등이 된다.

```text
1등
2등
2등
4등
5등
```

### 기본 형식

```sql
SELECT 필드1, 필드2,
       RANK() OVER (
           ORDER BY 정렬_기준_필드 [ASC|DESC]
       ) AS 순위
FROM 테이블명;
```

### 예시

학생들의 키가 큰 순서대로 순위를 구한다.

```sql
SELECT name, height,
       RANK() OVER (
           ORDER BY height DESC
       ) AS '키순위'
FROM students
LIMIT 0, 5;
```

`height DESC`이므로 키가 가장 큰 학생부터 1위가 부여된다.

---

## DENSE_RANK()

`DENSE_RANK()`도 `RANK()`와 마찬가지로 순위를 계산한다.

하지만 동점자가 있어도 **다음 순위를 건너뛰지 않는다.**

```text
RANK()
1등
2등
2등
4등

DENSE_RANK()
1등
2등
2등
3등
```

### 기본 형식

```sql
SELECT 필드1, 필드2,
       DENSE_RANK() OVER (
           ORDER BY 정렬_기준_필드 [ASC|DESC]
       ) AS 순위
FROM 테이블명;
```

### 예시

```sql
SELECT name, height,
       DENSE_RANK() OVER (
           ORDER BY height DESC
       ) AS '키순위'
FROM students
LIMIT 0, 5;
```

### RANK()와 DENSE_RANK() 비교

| 함수 | 동점자 | 동점자 다음 순위 |
|---|---|---|
| `RANK()` | 같은 순위 | 순위를 건너뜀 |
| `DENSE_RANK()` | 같은 순위 | 순위를 건너뛰지 않음 |

# PARTITION BY

`PARTITION BY`는 데이터를 지정한 기준에 따라 나눈 뒤 **각 그룹 안에서 윈도우 함수를 계산**할 때 사용한다.

```sql
SELECT 필드1, 필드2,
       RANK() OVER (
           PARTITION BY 그룹_기준_필드
           ORDER BY 정렬_기준_필드 [ASC|DESC]
       ) AS 순위
FROM 테이블명;
```

### 예시

3학년 학생을 대상으로 **각 학과 안에서** 키가 큰 순서대로 순위를 구한다.

```sql
SELECT name, department_id, height,
       RANK() OVER (
           PARTITION BY department_id
           ORDER BY height DESC
       ) AS '학과별 키 순위'
FROM students
WHERE grade = 3;
```

`PARTITION BY department_id`에 의해 학과별로 데이터가 나뉘고, 각 학과 안에서 `height DESC` 순서로 순위가 계산된다.

즉, 학과가 바뀌면 순위가 다시 1위부터 시작한다.

---

## GROUP BY와 PARTITION BY

`GROUP BY`와 `PARTITION BY`는 모두 데이터를 그룹으로 나눌 때 사용하지만 결과에 차이가 있다.

| 구분 | GROUP BY | PARTITION BY |
|---|---|---|
| 역할 | 같은 값을 하나의 그룹으로 묶음 | 계산 범위를 그룹별로 나눔 |
| 결과 행 | 여러 행이 하나의 결과로 집계됨 | 기존 행을 그대로 유지 |
| 주로 사용 | 집계 결과 조회 | 순위, 누적값 등 윈도우 함수 |

```text
GROUP BY
여러 행 → 그룹별 하나의 결과

PARTITION BY
원래 행 유지 → 그룹 안에서 각각 계산
```

# 윈도우 함수와 집계 함수

윈도우 함수는 기존의 집계 함수와 함께 사용할 수 있다.

사용할 수 있는 대표적인 집계 함수는 다음과 같다.

```text
SUM()
AVG()
COUNT()
MAX()
MIN()
```

집계 함수 뒤에 `OVER()`를 사용하면 기존 행을 유지하면서 윈도우 단위의 집계 결과를 구할 수 있다.

---

## 누적 합계

`SUM()`을 윈도우 함수로 사용하면 현재 행까지의 **누적 합계**를 구할 수 있다.

```sql
SUM(필드) OVER (
    PARTITION BY 그룹_기준
    ORDER BY 정렬_기준
)
```

예를 들어 도시별 판매량을 순서대로 누적해서 계산할 수 있다.

```text
Rome
200 → 200
300 → 500
400 → 900

Paris
500 → 500
300 → 800

London
100 → 100
400 → 500
```

`PARTITION BY`로 도시를 나누면 도시가 바뀔 때마다 누적 계산이 다시 시작된다.

---

## COUNT()와 윈도우 함수

`COUNT()` 역시 `OVER()`와 함께 사용할 수 있다.

### 학과별 학생 수 누적 집계

```sql
SELECT id, name, department_id,
       COUNT(*) OVER (
           PARTITION BY department_id
           ORDER BY id
       ) AS '학과별 누적 학생 수'
FROM students
ORDER BY department_id, id;
```

`PARTITION BY department_id`로 학과를 나누고 `id` 순서대로 학생 수를 누적한다.

예를 들어 같은 학과의 학생들이 다음과 같이 계산된다.

```text
학생 1 → 1
학생 2 → 2
학생 3 → 3
학생 4 → 4
...
```

다른 학과로 넘어가면 다시 1부터 계산된다.

# 핵심 정리

```text
윈도우 함수
→ 기존 행을 유지하면서 순위·집계 등을 계산

OVER()
→ 윈도우 함수의 계산 범위를 지정

PARTITION BY
→ 데이터를 그룹으로 나누고 그룹 안에서 계산

ORDER BY
→ 그룹 안에서 계산할 순서를 지정

RANK()
→ 동점자는 같은 순위
→ 다음 순위는 건너뜀
→ 1, 2, 2, 4

DENSE_RANK()
→ 동점자는 같은 순위
→ 다음 순위를 건너뛰지 않음
→ 1, 2, 2, 3

집계함수 + OVER()
→ SUM(), AVG(), COUNT(), MAX(), MIN() 등을
   윈도우 함수로 사용할 수 있음

GROUP BY
→ 행을 그룹별 결과로 묶음

PARTITION BY
→ 원래 행은 유지하면서 계산 범위만 나눔
```

## 기본 구조

```sql
윈도우함수() OVER (
    PARTITION BY 그룹_기준
    ORDER BY 정렬_기준
)
```

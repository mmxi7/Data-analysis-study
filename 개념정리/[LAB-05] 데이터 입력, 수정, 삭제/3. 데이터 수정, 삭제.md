# 데이터 수정, 삭제

## 데이터 수정하기

데이터를 수정할 때는 `UPDATE` 문을 사용한다.

```sql
UPDATE 테이블이름
SET 컬럼1 = 값,
    컬럼2 = 값, ...
[WHERE 조건]
```

- `UPDATE` : 수정할 대상 테이블을 지정
- `SET` : 변경할 컬럼과 새로운 값을 나열
- `컬럼 = 값` : 수정할 항목을 쉼표로 구분
- `WHERE` : 수정할 행을 지정하는 조건

> `WHERE` 절을 생략하면 모든 행이 수정되므로 주의해야 한다.

### 예시

학번이 10101인 학생의 학년을 2로, 학적 상태를 `휴학`으로 수정한다.

수정 전 데이터를 확인한다.

```sql
SELECT id, name, grade, status
FROM students
WHERE id = 10101;
```

데이터를 수정한다.

```sql
UPDATE students
SET grade = 2,
    status = '휴학'
WHERE id = 10101;
```

수정 결과를 확인한다.

```sql
SELECT id, name, grade, status
FROM students
WHERE id = 10101;
```

## 연산자를 활용한 데이터 수정

`UPDATE` 문에서는 기존 컬럼의 값을 이용하여 데이터를 수정할 수 있다.

### 예시

직급이 `부교수`인 교수의 급여를 10만원씩 인상한다.

수정 전 데이터를 확인한다.

```sql
SELECT name, position, sal
FROM professors
WHERE position = '부교수';
```

데이터를 수정한다.

```sql
UPDATE professors
SET sal = sal + 10
WHERE position = '부교수';
```

수정 결과를 확인한다.

```sql
SELECT name, position, sal
FROM professors
WHERE position = '부교수';
```

`sal = sal + 10`과 같이 기존 `sal` 값에 10을 더한 결과를 다시 `sal`에 저장할 수 있다.

## 데이터 삭제하기

데이터를 삭제할 때는 `DELETE` 문을 사용한다.

```sql
DELETE FROM 테이블이름
[WHERE 조건]
```

- `DELETE FROM` : 삭제할 대상 테이블을 지정
- `WHERE` : 삭제할 행을 지정하는 조건

> `WHERE` 절을 생략하면 모든 행이 삭제되므로 주의해야 한다.

`WHERE` 절에서는 `SELECT` 문과 동일하게 연산자를 사용할 수 있지만, 대부분의 경우 기본키가 일치하는 데이터에 대해서만 삭제하는 SQL을 주로 사용한다.

### 예시

학과 번호가 504번인 학과의 정보를 삭제한다.

삭제 전 정보를 확인한다.

```sql
SELECT *
FROM departments
WHERE id = 504;
```

데이터를 삭제한다.

```sql
DELETE FROM departments
WHERE id = 504;
```

삭제 후 데이터를 확인한다.

```sql
SELECT *
FROM departments
WHERE id = 504;
```

삭제가 정상적으로 완료되면 조회 결과가 `Empty set`으로 나타난다.

## 데이터 삭제시 주의사항

다른 테이블에서 참조하고 있는 부모 데이터를 삭제하려고 하면 참조 무결성 제약조건에 의해 삭제되지 않을 수 있다.

### 예시

학과 번호가 101번인 학과의 정보를 삭제한다.

삭제 전 정보를 확인한다.

```sql
SELECT *
FROM departments
WHERE id = 101;
```

데이터 삭제를 시도한다.

```sql
DELETE FROM departments
WHERE id = 101;
```

101이라는 값을 참조하고 있는 자식 데이터가 존재하기 때문에 참조 무결성 제약조건에 의해 삭제할 수 없다.

```text
ERROR 1451 (23000): Cannot delete or update a parent row: a foreign key constraint fails
```

즉, 자식 데이터가 부모 데이터를 참조하고 있는 경우 자식 데이터가 삭제되지 않으면 부모 데이터를 삭제할 수 없다.

# 핵심 정리

```text
UPDATE
→ 기존 데이터를 수정

SET
→ 변경할 컬럼과 새로운 값을 지정

WHERE
→ 수정하거나 삭제할 행을 지정
→ 생략하면 모든 행이 수정 또는 삭제되므로 주의

컬럼 = 컬럼 + 값
→ 기존 컬럼의 값을 이용하여 데이터 수정 가능

DELETE FROM
→ 테이블의 데이터를 삭제

참조키가 존재하는 데이터 삭제
→ 자식 데이터가 부모 데이터를 참조하고 있으면
   참조 무결성 제약조건에 의해 부모 데이터 삭제 불가

ERROR 1451
→ 자식 테이블에서 참조 중인 부모 데이터를
   삭제 또는 수정하려 할 때 발생
```

## 기본 구조

```sql
-- 데이터 수정
UPDATE 테이블명
SET 컬럼1 = 값,
    컬럼2 = 값
WHERE 조건;

-- 기존 값을 이용한 수정
UPDATE 테이블명
SET 컬럼 = 컬럼 + 값
WHERE 조건;

-- 데이터 삭제
DELETE FROM 테이블명
WHERE 조건;
```

# 트랜잭션의 이해

## 트랜잭션의 개념

- 하나의 DB에서 하나의 **논리 작업 단위**로 간주되는 일련의 SQL 묶음
SQL 묶음을 실행하는 중간에 오류가 발생하면 **데이터 불일치** 현상 발생

## 트랜잭션의 4대 특성 (ACID)
|특성|의미|설명|
|---|---|---|
|Atomicity (원자성)|All or Nothing|트랜잭션의 모든 완전히 수행되거나 수행되지 않아야 함|
|Consistency (일관성)|Integrity 유지|트랜잭션 전후로 데이터의 무결성이 유지되어야 함|
|Isolation (격리성)|독립 실행|동시에 여러 트랜잭션이 실행되어도 서로 간섭하지 않아야 함|
|Durability (지속성)|영속성|트랜잭션이 성공적으로 완료되면 그 결과는 영구적으로 저장됨|

## 트랜잭션 제어 명령어
- START TRANSACTION;
- COMMIT;
- ROLLBACK;
- SAVEPOINT ();
- ROLLBACK TO ();

# JOIN

## JOIN이란?

- RDBMS에서 두 개 이상의 테이블을 연결하여 관련 데이터를 하나의 결과 집합으로 조회
테이블 간의 **공통된 컬럼**을 기준으로 데이터를 연결
중복된 데이터를 줄이고 데이터 무결성 유지, 다양한 정보 연결 가능

## JOIN문 종류

- INNER JOIN
- LEFT [OUTER] JOIN
- RIGHT [OUTER] JOIN
- EQUI JOIN
- CROSS JOIN
- SELF JOIN

# INNER JOIN

## INNER JOIN이란?

- 양쪽 테이블 모두에 존재하는 값만 결과로 출력 (교집합)
- **참조키의 값이 일치하는 경우**를 조건으로 설정해야 함

## 구문
```
SELECT ...
FROM ...
INNER JOIN ... ON ...
```

# 데이터 검색하기 - 연습문제

## 01

급여가 500만원 이상인 교수들의 교수번호, 이름, 급여를 급여가 높은 순으로 조회하시오.

```sql
 SELECT id, name, sal FROM professors
 WHERE sal >= 500
 ORDER BY sal DESC;
```

---

## 02

3학년 여학생 중에서 키가 큰 상위 5명의 이름, 학년, 성별, 키를 키가 큰 순으로 조회하시오.

```sql
SELECT name, grade, gender, height FROM students
WHERE grade = 3 AND gender = '여'
ORDER BY height DESC
LIMIT 5;
```

---

## 03

급여가 300만원 이상인 교수 중에서 급여가 낮은 하위 3명의 교수번호, 이름, 급여를 급여가 낮은 순으로 조회하시오.

```sql
SELECT id, name, sal From professors
WHERE sal >= 300
ORDER BY sal
LIMIT 3;
```

---

## 04

학점이 2학점이 아니면서 3학점도 아닌 과목의 과목번호, 과목명, 학점을 조회하는 SQL문을 작성하시오.  
단, 과목명 가나다순으로 정렬하시오.

```sql
SELECT id, name, credit FROM subjects
WHERE credit NOT IN (2, 3)
ORDER BY name;
```

---

## 05

1학년이 아니면서 키가 180cm 이상인 남학생들의 이름, 학년, 키, 성별을 키가 큰 순으로 조회하시오.

```sql
SELECT name, grade, height, gender FROM students
WHERE grade != 1 AND height >= 180 AND gender = '남'
ORDER BY height DESC;
```

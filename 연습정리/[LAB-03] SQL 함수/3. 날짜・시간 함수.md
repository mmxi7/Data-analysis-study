# 날짜·시간 함수

## 01

`professors` 테이블에서 각 교수의 입사일로부터 현재까지 근속 연수(년)를 계산하시오.

```sql
SELECT name AS 교수이름, hiredate AS 입사일, FLOOR(DATEDIFF(CURDATE(), hiredate) / 365) AS 근속 연수
FROM professors;
```

---

## 02

`departments` 테이블에서 설립 연도가 30년 이상 지난 학과명과 설립 연도를 조회하시오.

```sql
SELECT dname AS 학과명, established AS 설립연도
FROM departments
WHERE YEAR(CURDATE()) - established >= 30;
```

## 03

`students` 테이블에서 생년월일을 `'MM월 DD일'` 형식으로 변환하여 출력하시오.

```sql
SELECT name AS 학생이름, birthdate AS 생년월일, DATE_FORMAT(birthdate, '%m월 %d일') AS 생일_형식
FROM students;
```

## 04

`enrollments` 테이블에서 수강신청일로부터 30일 후 날짜를 다음 시험일로 가정하고 출력하시오.

```sql
SELECT
  student_id,
  subject_id,
  enroll_date AS 수강신청일,
  DATE_ADD(enroll_date, INTERVAL 30 DAY) AS 시험예정일
FROM enrollments;
```

## 05

`students` 테이블에서 생년월일을 기준으로 나이가 가장 많은 학생의 이름과 나이(년)를 출력하시오.

### 방법 1. DATEDIFF() 사용

현재 날짜와 생년월일의 차이를 일수로 구한 뒤 `365`로 나누어 나이를 계산한다.

```sql
SELECT
  name AS 학생이름,
  birthdate AS 생년월일,
  FLOOR(DATEDIFF(CURDATE(), birthdate) / 365) AS 나이
FROM students
ORDER BY 나이 DESC
LIMIT 0, 1;
```

- `DATEDIFF()` : 현재 날짜와 생년월일의 차이를 일수로 계산
- `/ 365` : 일수를 연 단위로 변환
- `FLOOR()` : 소수점 이하를 내림하여 정수로 변환

### 방법 2. YEAR() 사용

현재 연도에서 출생 연도를 빼고 `1`을 더하여 한국식 세는나이를 계산한다.

```sql
SELECT
  name AS 학생이름,
  birthdate AS 생년월일,
  YEAR(CURDATE()) - YEAR(birthdate) + 1 AS 나이
FROM students
ORDER BY 나이 DESC
LIMIT 0, 1;
```

- `YEAR()` : 날짜에서 연도만 추출
- `현재 연도 - 출생 연도 + 1` : 한국식 세는나이 계산

> 두 방법은 나이를 계산하는 기준이 다르기 때문에 결과가 다를 수 있다.
> `DATEDIFF()`를 이용한 방법은 경과 일수를 기준으로 계산하고, `YEAR()`를 이용한 방법은 출생 연도를 기준으로 세는 나이를 계산한다.

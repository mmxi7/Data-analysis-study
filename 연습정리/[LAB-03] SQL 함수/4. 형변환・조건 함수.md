# 형변환·조건 함수

## 01

`students` 테이블에서 학생의 이름(`name`)과 학년(`grade`)을 조회하고, 학년에 따라 다음과 같이 `"구분"`을 표시하시오.

- 1학년: 신입생
- 2학년: 재학생
- 3학년: 재학생
- 4학년: 졸업반

```sql
SELECT name, grade,
  CASE
    WHEN grade = 1 THEN '신입생'
    WHEN grade = 4 THEN '졸업반'
    ELSE '재학생'
  END AS 구분
FROM students;
```

## 02

`students` 테이블에서 학생의 이름, 키, 키상태를 조회하시오.

키상태는 학생의 키가 170cm 이상이면 `NULL`, 그보다 작으면 `'작음'`이라고 표시하되, 이 결과가 `NULL`일 경우에는 `'경고'`라는 문자열로 대체하여 출력하시오.

```sql
SELECT name, height, IFNULL(IF(height >= 170, NULL, '작음'), '경고') AS 키상태
FROM students;
```

## 03

`departments` 테이블에서 학과명(`dname`)과 설립 연도(`established`)를 조회하시오.

설립 연도는 `'YYYY년'` 형식의 문자열로 변환하여 `'설립연도'`라는 별칭으로 표시하시오.

```sql
SELECT dname, CONCAT(CAST(established AS CHAR), '년') AS 설립연도
FROM departments;
```

## 04

`students` 테이블에서 학생의 이름, 성별, 성별 정보를 조회하시오.

성별 정보는 다음과 같이 구분하시오.

- `남` → `Male`
- `여` → `Female`
- 그 외 → `기타`
- 성별 정보가 입력되지 않은 경우 → `미입력`

```sql
SELECT name, gender,
  CASE
    WHEN gender IS NULL THEN '미입력'
    WHEN gender = '남' THEN 'Male'
    WHEN gender = '여' THEN 'Female'
    ELSE '기타'
  END AS '성별 정보'
FROM students;
```

## 05

`students` 테이블에서 학생들의 키와 몸무게를 활용하여 건강 지수를 계산하시오.

건강 지수는 **키(cm)의 제곱을 몸무게(kg)로 나눈 값**을 소수점 둘째 자리까지 반올림하여 `'건강지수'`로 출력하시오.

건강 지수가

- `350 이상` → `우수`
- `300 이상` → `양호`
- 그보다 작음 → `주의`

라고 판단하여 `'건강등급'`으로 함께 표시하시오.

```sql
SELECT name, height, weight, ROUND(POWER(height, 2) / weight, 2) AS 건강지수,
  CASE
    WHEN ROUND(POWER(height, 2) / weight, 2) >= 350 THEN '우수'
    WHEN ROUND(POWER(height, 2) / weight, 2) >= 300 THEN '양호'
    ELSE '주의'
  END AS 건강등급
FROM students;
```

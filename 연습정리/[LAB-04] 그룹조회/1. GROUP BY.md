# GROUP BY

## 01

교수의 직급(position)별 교수 수를 출력하시오.

```sql
SELECT position AS 직급, COUNT(*) AS '교수 수'
FROM professors
GROUP BY position;
```

---

## 02

학생들의 성별(gender)에 대한 평균 몸무게를 계산하시오.

```sql
SELECT gender AS 성별, AVG(weight) AS '평균 몸무게'
FROM students
GROUP BY gender;
```

---

## 03

학생 수가 10명 초과인 학년과 학생수를 조회하시오.

```sql
SELECT grade AS 학년, COUNT(*) AS 학생수
FROM students
GROUP BY grade
HAVING 학생수 > 10;
```

---

## 04

수강신청일 기준으로 연도별 신청 건수와 평균 점수를 구하시오.

```sql
SELECT YEAR(enroll_date) AS 연도, COUNT(*) AS '신청 건수', AVG(score) AS '평균 점수'
FROM enrollments
GROUP BY YEAR(enroll_date);
```

---

## 05

`students` 테이블에서 학적상태(status)별로 학생 수와 평균 키를 구하고,  
평균 키가 165cm 이상인 상태만 출력하시오.  
평균 키가 높은 순으로 정렬하시오.

```sql
SELECT status AS '학적 상태', COUNT(*) AS '학생 수', AVG(height) AS '평균 키'
FROM students
GROUP BY status
HAVING `평균 키` >= 165
ORDER BY `평균 키` DESC;
```

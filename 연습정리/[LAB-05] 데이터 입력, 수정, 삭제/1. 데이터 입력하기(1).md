# 데이터 입력하기(1)

## 01

`departments` 테이블에 학과명은 소프트웨어공학과, 위치는 2호관, 전화번호는 051-123-7890, 이메일은 sw@myschool.ac.kr, 설립연도는 2012, 홈페이지는 http://sw.myschool.ac.kr인 새로운 학과를 등록하세요. 학과 번호는 자동으로 생성되도록 합니다.

```sql
INSERT INTO departments (id, dname, loc, phone, email, established, homepage) VALUES (NULL, '소프트웨어공학과', '2호관', '051-123-7890', 'sw@myschool.ac.kr', 2012, 'http://sw.myschool.ac.kr');
SELECT * FROM departments ORDER BY id DESC LIMIT 0, 3;
```

## 04

102번 학과의 이름을 '소프트웨어학과'로, 위치를 '공학관'으로 수정하세요.

```sql
SELECT id, dname, loc FROM departments WHERE id = 102;
UPDATE departments SET dname = '소프트웨어학과', loc = '공학관' WHERE id = 102;
SELECT id, dname, loc FROM departments WHERE id = 102;
```
